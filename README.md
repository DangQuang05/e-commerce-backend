# E-commerce backend

This project is for personal learning purpose.

## Tech Stack

- **Language:** Java 17
- **Build Tool:** Maven
- **Framework:** Spring Boot 4.1.0
- **Database:** PostgreSQL

## Prerequisites

- JDK 17
- Maven 3.9+
- PostgreSQL 18+

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DangQuang05/e-commerce-backend.git
   cd e-commerce-backend
   ```

2. **Run the project:**
    ```bash
    mvn spring-boot:run
    ```
